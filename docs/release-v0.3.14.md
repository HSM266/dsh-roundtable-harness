多模型圆桌辩论插件：让本机已配置的模型坐上一张桌子，带着各自人设围绕同一话题多轮互喷。
每一轮都把全部历史发言打包给下一位；结束后裁判按六维加权打分，性价比另用 cost-meter 真实账单算。

## 这一版的重点

- **调用耗时可量了**：战报新增一节，按选手列出平均耗时、输出 tokens、输出速率（tok/s）、超时次数与空响应次数，并标出全场最慢一轮。超时和空响应**不进平均值**——它们说明没答上，不能当作「这家慢」的证据。
- **花费归因不再错位**：cost-meter 是批量写盘的，以前只等「文件变过」就取增量，第一次新写入常属于上一位选手，于是战报出现「无法归因到 glm-5.3，账本里这段时间的键是 dashscope:kimi-k3」。现在等的是**这个模型自己的**增量，等不到才记归因失败。
- **空响应能自证了**：`empty` 不再只有一句「模型返回内容为空」，会带上 `finish` 原因、token 数与原始片段，能区分内容过滤、预算耗尽与真空响。

## 自 v0.3.11 以来的修复

- 战报与 docx 的默认输出目录改为 `$DSH_HOME/roundtable/reports`（此前落在宿主工作目录，本机正好是 profile 目录），目录不存在自动创建
- 形象图填「复制为路径」得到的带引号路径（`"D:\pics\a.png"`）不再被当成相对路径，也兼容 `file://`
- CI 改用 npm（仓库只有 `package-lock.json`，`setup-node` 的 pnpm 缓存会直接失败），新增打包内容检查

## 核心能力（未变）

- **六维评分**：攻击性 / 逻辑 / 人设形象还原度 / 趣味度 / 策略 / 深度，权重可调
- **性价比单列**：只收每一轮花费都成功归因的选手，没测到的不进榜，不用估算填坑
- **裁判可降级**：裁判返回的 id 全都对不上时判为降级并写明原因，不谎称「已裁判」
- **共享上下文**：结构性强制，不靠提示词约定；超预算时用最便宜的选手压缩旧轮次
- **战报与导出**：Markdown《赛博圆桌战报》+ docx（封面、形象图、六维榜、耗时表、逐轮、异常）
- **终止与续接**：终止是真 AbortSignal 且跳过裁判；续前讨论在上一场基础上继续加轮次
- **入口**：右上角悬浮挂件（96px、可拖动、位置记住）+「设置 → 圆桌会议」

## 兼容

DSH `>=0.2.0-rc.1 <0.3.0-0`（实测 0.2.0-rc.2）· Node ≥ 20 · React 18 由宿主提供。0.1.x 不支持。

## 安装

```sh
# npm（推荐，同源可追溯）
dsh plugin --profile <PROFILE> add dsh-roundtable-harness@0.3.14

# 或本地附件
dsh plugin --profile <PROFILE> add ./dsh-roundtable-harness-0.3.14.tgz
```

装完重启一次 `dsh web`，刷新页面：右上角看板娘挂件点一下即开。

## 验证

`npm run verify` 覆盖 45 项，其中与本版相关的是：等的是本模型那一笔账而不是文件戳、失败轮次不进耗时平均值、归因失败不做当日总额兜底。

## 已知边界

- 性价比榜是实验功能，花费来自外部账本，名次仅供参考
- 形象图只用于设置页预览与 docx 封面，**不会发给模型**；模型看到的只有人设文本与别人的发言
- 敏感词正则只做静态体检（零宽 / 嵌套量词 / 反向引用拒收），不保证覆盖所有灾难性回溯形态
