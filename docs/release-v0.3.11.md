多模型圆桌辩论插件：让本机已配置的模型坐上一张桌子，带着各自人设围绕同一话题多轮互喷。
每一轮都把全部历史发言打包给下一位；结束后裁判按六维加权打分，性价比另用 cost-meter 真实账单算。

## 这一版有什么

- **六维评分**：攻击性 / 逻辑 / 人设形象还原度 / 趣味度 / 策略 / 深度，权重可调，总分 = 加权平均
- **真实花费**：逐次调用前后读 dsh-cost-meter 账本，按精确 `provider:model` 归因；任一轮归因失败就整人排除出性价比榜，不拿估算填坑
- **裁判可降级**：裁判返回的 id 全都对不上时判为降级并写明原因，不谎称「已裁判」
- **共享上下文**：结构性强制，不靠提示词约定；超预算时用最便宜的选手压缩旧轮次
- **战报与导出**：Markdown《赛博圆桌战报》+ docx（封面、形象图、六维榜、逐轮、异常章节），模型输出先转义再落盘
- **终止与续接**：「终止讨论」是真 AbortSignal 且跳过裁判；「续前讨论」在上一场基础上继续加轮次
- **入口**：右上角悬浮挂件（96px、可拖动、位置记住）+「设置 → 圆桌会议」

## 安装

```sh
# npm（推荐，同源可追溯）
dsh plugin --profile <PROFILE> add dsh-roundtable-harness

# 或本地附件
dsh plugin --profile <PROFILE> add ./dsh-roundtable-harness-0.3.11.tgz
```

装完重启一次 `dsh web`，刷新页面：右上角看板娘挂件点一下即开。

## 验证

`npm run verify` 覆盖 41 项：花费归因不兜底、性价比只收数据完整的人、零宽与嵌套量词正则拒收、IPv6 私网全写法拦截、战报转义、429 与内部异常都保留部分战报、续前讨论接续、docx 真实解压校验、带引号形象图路径、客户端信封拆解与槽位注册等。

## 已知边界

- 性价比榜是实验功能，花费来自外部账本，名次仅供参考
- 敏感词正则只做静态体检（零宽 / 嵌套量词 / 反向引用拒收），不保证覆盖所有灾难性回溯形态
